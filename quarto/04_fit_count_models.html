Count models

Each input row represents one participant, with a count and a follow-up duration. A for loop repeats the same formula for each outcome named in count_outcomes. glm.nb() fits a negative binomial model, which allows more variation in counts than a Poisson model. offset(log(followup_time_itt)) accounts for exposure time with its coefficient fixed at one. tbl_regression(exp = TRUE) converts log-scale coefficients to rate ratios, and tbl_stack() combines the outcome tables.

An invented rate ratio of 0.80 means a rate 20% lower in the intervention arm; it does not mean 20% fewer participants had an event. The confidence interval describes the precision of that estimated ratio. See the MASS function reference for fitting details (MASS authors, n.d.).

Why the offset turns counts into rates, and why the exponentiated coefficients are incidence rate ratios, is in Longitudinal data and mixed models.

Click to show/hide R Code 
# Negative binomial regression of each count on arm, with log follow-up time
# as an offset; incidence rate ratios, one row per outcome
count_model_table <- NULL

for (outcome in count_outcomes) {
  outcome_formula <- paste0(
    outcome, " ~ ", "studyarm + offset(log(followup_time_itt))"
  ) %>%
    as.formula()

  outcome_table <- glm.nb(outcome_formula, data = rescue_medication_merged) %>%
    tbl_regression(
      exp = TRUE,
      show_single_row = "studyarm",
      label = list(studyarm ~ outcome)
    ) %>%
    modify_header(label = "**Outcome**")

  if (is.null(count_model_table)) {
    count_model_table <- outcome_table
  } else {
    count_model_table <- tbl_stack(list(count_model_table, outcome_table))
  }
}

Count interaction models

These loops add one subgroup at a time; they do not fit all subgroup variables together. studyarm * subgroup includes the arm term, subgroup term and their interaction. The named list stores each table first by outcome and then by subgroup, making the analysis that generated it identifiable. Read the reference category before interpreting the arm coefficient: it now applies within that category.

What each coefficient of an arm × subgroup model means is in Interactions, what the interaction p-value tests in What a p-value for interaction means, and how to get the IRR in each subgroup level in Effects behind an interaction.

# Arm-by-subgroup interactions for each count outcome
count_interaction_tables <- list()

for (outcome in count_outcomes) {
  count_interaction_tables[[outcome]] <- list()

  for (subgroup in count_subgroup_variables) {
    outcome_formula <- paste0(
      outcome, " ~ ", "studyarm*", subgroup,
      " + offset(log(followup_time_itt))"
    ) %>%
      as.formula()

    count_interaction_tables[[outcome]][[subgroup]] <-
      glm.nb(outcome_formula, data = rescue_medication_merged) %>%
      tbl_regression(exp = TRUE)
  }
}

# Baseline asthma control, not fitted for hospitalizations
for (outcome in act_subgroup_count_outcomes) {
  for (subgroup in c("act_binary")) {
    outcome_formula <- paste0(
      outcome, " ~ ", "studyarm*", subgroup,
      " + offset(log(followup_time_itt))"
    ) %>%
      as.formula()

    count_interaction_tables[[outcome]][[subgroup]] <-
      glm.nb(outcome_formula, data = rescue_medication_merged) %>%
      tbl_regression(exp = TRUE) %>%
      modify_caption(paste0("**", outcome, "**"))
  }
}

Rescue models alternative

These additional fits were retained from the earlier analysis. Their formula uses log(offset(followup_time_itt)), which is not the working offset syntax shown above; #1 tracks the correction. Treat this block as a documented implementation problem, not as a second recommended way to specify a rate model.

# A second fit of the rescue models from the RMD's medication chunk. As
# written, log(offset(...)) enters follow-up time as a covariate, not an
# offset. See issue #1.
rescue_puffs_model_alt_table <- glm.nb(
  rescue_puffs_itt ~ studyarm + log(offset(followup_time_itt)),
  data = rescue_medication_merged
) %>%
  tidy(., conf.int = TRUE, exp = TRUE) %>%
  flextable()

rescue_days_model_alt_table <- glm.nb(
  rescue_days_itt ~ studyarm + log(offset(followup_time_itt)),
  data = rescue_medication_merged
) %>%
  tidy(., conf.int = TRUE, exp = TRUE) %>%
  flextable()

Controller PDC comparison

PDC is a proportion for each participant, so this block summarizes it by arm rather than fitting the count model above. add_p() asks gtsummary to choose its default comparison test. The resulting table’s footnote identifies the test; readers should not assume it is a t test. The gtsummary tutorial explains summary statistics, missing rows and test annotations (gtsummary authors, n.d.).

# Controller PDC for the year by arm, with gtsummary's default test
controller_pdc_comparison <- controller_medication_merged %>%
  select(controller_pdc_pp, controller_pdc_itt, studyarm) %>%
  tbl_summary(by = studyarm) %>%
  add_p()
