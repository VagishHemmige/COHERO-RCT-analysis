Effects behind an interaction

  • Show All Code
  • Hide All Code
  • View Source
Author

Vagish Hemmige

A model with an interaction holds the arm effect for every subgroup level and every visit, but its coefficients show only some of them directly (see Interactions). This page shows two ways to get all of them, with confidence intervals, from a model already fitted. Both give the same answer. The code is shown, not run, and uses illustrative object names.

By hand from the coefficients

The arm effect in a non-reference level is a sum of coefficients, so its variance is a sum of variances and covariances. For the count model rescue_puffs_itt ~ studyarm * prefer_language + offset(...):

\[ \log \text{IRR}_{\text{Spanish}} = \beta_{\text{arm}} + \beta_{\text{arm} \times \text{Spanish}} \]

\[ \text{Var} = \text{Var}(\beta_{\text{arm}}) + \text{Var}(\beta_{\text{arm} \times \text{Spanish}}) + 2\,\text{Cov}(\beta_{\text{arm}}, \beta_{\text{arm} \times \text{Spanish}}) \]

Click to show/hide R Code 
b <- coef(fit)
v <- vcov(fit)
terms <- c("studyarm1", "studyarm1:prefer_languageSpanish")

log_irr <- sum(b[terms])
se <- sqrt(sum(v[terms, terms]))     # the sum of the 2 x 2 block

exp(log_irr)                          # IRR in Spanish speakers
exp(log_irr + c(-1, 1) * qnorm(0.975) * se)

The same idea works for any combination: the arm difference at the 6-month visit in one subgroup level of a mixed model is the sum of the baseline arm term and the relevant two- and three-way terms.

By refitting with a different reference level

The coefficient for studyarm1 is the arm effect in the reference level, so making the other level the reference gives its effect directly:

Click to show/hide R Code 
participants_spanish_ref <- participants %>%
  mutate(prefer_language = relevel(prefer_language, ref = "Spanish"))

fit_spanish_ref <- glm.nb(
  rescue_puffs_itt ~ studyarm * prefer_language + offset(log(followup_time_itt)),
  data = participants_spanish_ref
)
# exp(coef(fit_spanish_ref)["studyarm1"]) is now the IRR in Spanish speakers

This is the same model, coded differently: it fits identically, and the interaction p-value doesn’t change. Recoding the reference level this way is also what the plotting function’s “model C” does (see How this code does it).

With emmeans

emmeans computes these combinations from the fitted model, without refitting and without writing out terms by hand (Lenth and Piaskowski 2026). For the count model:

Click to show/hide R Code 
library(emmeans)

emmeans(fit, ~ studyarm | prefer_language, type = "response") %>%
  contrast("revpairwise")

This gives one row per language: the intervention-vs-control IRR (a ratio column) with its confidence interval. On the log scale, comparisons are differences of logs, which become ratios when back-transformed. Both arms are compared at the same follow-up time, so the offset cancels out of the ratio.

For the mixed model, the arm difference at each visit within each subgroup level:

Click to show/hide R Code 
emmeans(fit_lmer, ~ studyarm | time_factor * prefer_language) %>%
  contrast("revpairwise")

These are differences on the score scale, with no baseline subtraction. To get the change-from-baseline differences that the model’s interaction terms describe, ask for an interaction contrast between arms and between each visit and baseline:

Click to show/hide R Code 
emmeans(fit_lmer, ~ studyarm * time_factor | prefer_language) %>%
  contrast(interaction = c("revpairwise", "trt.vs.ctrl"))

For lmer models, emmeans chooses its own degrees-of-freedom method (Kenward–Roger or Satterthwaite; see its documentation), so p-values can differ slightly from the ones lmerTest reports.

Check that the methods agree

On synthetic data, the hand calculation, the refit with a new reference level and emmeans should give the same estimate and, for the count models, the same confidence interval. Showing that is a good test that the right terms were combined. These calls are checked against emmeans’ help pages for the installed version before they’re used in the analysis.

References

Lenth, Russell V., and Julia Piaskowski. 2026. Emmeans: Estimated Marginal Means, Aka Least-Squares Means. https://rvlenth.github.io/emmeans/.

## By hand from the coefficients

$$
\log \text{IRR}_{\text{Spanish}} = \beta_{\text{arm}} + \beta_{\text{arm} \times \text{Spanish}}
$$

$$
\text{Var} = \text{Var}(\beta_{\text{arm}}) + \text{Var}(\beta_{\text{arm} \times \text{Spanish}}) + 2\,\text{Cov}(\beta_{\text{arm}}, \beta_{\text{arm} \times \text{Spanish}})

## With emmeans

emmeans computes these combinations from the fitted model, without refitting and without writing out terms by hand [@lenth2026emmeans]. For the count model:

```{r}

  contrast("revpairwise")
```

For the mixed model, the arm difference at each visit within each subgroup level:

