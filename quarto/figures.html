ACT plots

ACT denotes the asthma-control score used in the code. In the visit panels, each point is an observed participant score; horizontal spreading helps reveal overlapping points. The trajectory plots connect a participant’s recorded visits. A connecting segment does not provide measurements between visits. A separate scatterplot compares self-reported adherence with interval app-recorded PDC; agreement between these measures is a different question from whether the intervention changed either one.

Count outcome plots

The loop creates one plot per count outcome and saves it under that outcome’s name. Each point is a participant-level count. The plot makes skewness, many zeros and unusually large counts visible; it neither adjusts for follow-up nor establishes that an unusual value is an error. aes() maps variables to positions and colors, while geom_*() chooses marks. The ggplot2 introduction explains this layering (ggplot2 authors, n.d.).

      x = studyarm, y = .data[[outcome]], color = studyarm
    )) +

}

Mixed model plots overall

Faint trajectories show recorded measurements, while prominent points and lines show model-estimated group means. Error bars are confidence intervals for those means, not the range containing most individual scores. The table under the plot, “Observed, n”, counts the participants with the outcome recorded at each visit; it is not necessarily the model sample if predictors are missing. Follow-up p-values marked with a dagger test differences in change from baseline, so they do not simply test the visible gap between the two means at that visit.

What the plotted means, error bars and p-values come from is in How this code does it.

Click to show/hide R Code 
# Outcome over time by arm, for each outcome, drawn from the estimates of the
# models fitted in 05_fit_mixed_models.R
mixed_model_plots <- list()

for (population in names(mixed_model_data)) {
  mixed_model_plots[[population]] <- list()

  for (outcome in repeated_outcomes) {
    plot_title <- paste0(
      figure_label(outcome, figure_labels), " over time, ", population_labels[[population]]
    )

    mixed_model_plots[[population]][[outcome]] <- list()
    mixed_model_plots[[population]][[outcome]][["overall"]] <-
      compose_trajectory_figure(
        mixed_model_data[[population]],
        mixed_model_estimates[[population]][[outcome]][["overall"]],
        outcome,
        title = plot_title,
        arm_labels = arm_labels, labels = figure_labels
      )
  }
}

Mixed model plots subgroups

The loops add one subgroup at a time and return plots in a list indexed by population, outcome and subgroup. The within-panel p-values and between-subgroup p-values answer different questions. At follow-up the latter concern differences in the change-from-baseline arm contrast. Read the interaction explanation before comparing a small p-value in one panel with a large one in another.

The script creates plot objects in memory and does not export them. The website displays this code without showing participant-derived plots.

Each subgroup level has its own column with its own participants, side by side on the same scale. Under the panels, one row of p-values tests the contrast within each level and another, under each level after the first, tests its difference from the first level; see How to read the trajectory figure, How this code does it and What a p-value for interaction means.

Click to show/hide R Code 
# Outcome over time by arm, stratified by each subgroup; child or adult only
# for outcomes measured in both groups (subgroup_analyses, from
# 05_fit_mixed_models.R)
for (population in names(mixed_model_data)) {
  for (analysis in subgroup_analyses) {
    outcome <- analysis$outcome

    for (subgroup in analysis$subgroups) {
      plot_title <- paste0(
        figure_label(outcome, figure_labels), " over time, by ",
        tolower(figure_label(subgroup, figure_labels)), ", ",
        population_labels[[population]]
      )

      mixed_model_plots[[population]][[outcome]][[subgroup]] <-
        compose_trajectory_figure(
          mixed_model_data[[population]],
          mixed_model_estimates[[population]][[outcome]][[subgroup]],
          outcome,
          modifier = subgroup,
          title = plot_title,
          arm_labels = arm_labels, labels = figure_labels
        )
    }
  }
}
