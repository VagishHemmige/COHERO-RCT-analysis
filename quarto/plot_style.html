Check the ggplot2 version

The theme relies on features added in ggplot2 4.0.0: a theme can carry the palettes its figures use, and labels can be looked up by variable name. On an older version the script stops with a message saying what to update, rather than failing later with a less helpful error.

Palettes

A palette is the ordered set of colours (or shapes, or line types) given to the groups in a figure. The colours are the Okabe-Ito set, chosen to stay distinguishable for people with the common kinds of colour-vision deficiency, with a neutral dark grey first so the control arm recedes and the intervention arm stands out. Groups also differ by point shape and line type, so a figure still works in greyscale and never relies on colour alone.

Click to show/hide R Code 
# Okabe-Ito colours (safe for the common kinds of colour-vision deficiency),
# with a neutral dark grey first: the first group of any factor, such as the
# control arm or a reference level, is drawn in grey and the second in blue
okabe_ito <- unname(grDevices::palette.colors(palette = "Okabe-Ito"))
publication_colours <- c("#555555", okabe_ito[c(6, 7, 4, 2, 8, 3, 5)])

# Shapes and line types differ too, so groups never rely on colour alone.
# Filled shapes 21-25 take a white fill, so overlapping points stay visible.
publication_shapes <- c(21, 24, 22, 23, 25)
publication_linetypes <- c("22", "solid", "42", "12", "4212")

The publication theme

A theme controls everything in a figure that is not data: background, gridlines, text sizes, legend position. theme_publication() keeps only what helps a reader: light horizontal gridlines to read values against, thin axis lines, no panel border. It also carries the palettes above, so a figure needs no colour settings of its own. Text sizes are set for the printed figure (9 points by default), so a figure should be saved at the size it will be printed.

Click to show/hide R Code 
# A quiet theme for print: no panel border, light horizontal gridlines only,
# thin axis lines, text sized for the printed figure. The legend sits above
# the panel; figures that name their groups on the plot itself remove it.
theme_publication <- function(base_size = 9, base_family = "",
                              header_family = NULL) {
  ggplot2::theme_minimal(
    base_size = base_size,
    base_family = base_family,
    header_family = header_family
  ) +
    ggplot2::theme(
      panel.grid.minor = ggplot2::element_blank(),
      panel.grid.major.x = ggplot2::element_blank(),
      panel.grid.major.y = ggplot2::element_line(
        colour = "grey90", linewidth = 0.3
      ),
      axis.line.x = ggplot2::element_line(colour = "grey30", linewidth = 0.3),
      axis.ticks.x = ggplot2::element_line(colour = "grey30", linewidth = 0.3),
      axis.title = ggplot2::element_text(colour = "grey20"),
      axis.text = ggplot2::element_text(colour = "grey30"),
      strip.text = ggplot2::element_text(face = "bold", hjust = 0),
      plot.title = ggplot2::element_text(face = "bold"),
      plot.title.position = "plot",
      plot.caption = ggplot2::element_text(colour = "grey35", hjust = 0),
      plot.caption.position = "plot",
      legend.position = "top",
      legend.justification = "left",
      palette.colour.discrete = publication_colours,
      palette.fill.discrete = publication_colours,
      palette.shape.discrete = scales::pal_manual(publication_shapes),
      palette.linetype.discrete = publication_linetypes
    )
}

Labels

label_figure() replaces column names with the readable names in figure_labels (defined on Setup), and arm codes with “Control” and “Intervention”. figure_label() looks up one name, for titles and axis labels built in code.

Click to show/hide R Code 
# Axis and legend titles from figure_labels (setup.R), looked up by variable
# name, so no raw column name reaches a figure; arm names in place of their
# codes in the legend and, with arm_axis = TRUE, on a study-arm x-axis
label_figure <- function(arm_axis = FALSE) {
  layers <- list(
    ggplot2::labs(dictionary = figure_labels),
    ggplot2::scale_colour_discrete(labels = arm_labels)
  )
  if (arm_axis) {
    layers <- c(layers, list(ggplot2::scale_x_discrete(labels = arm_labels)))
  }
  layers
}

# One variable's figure label, or its name when it has none
figure_label <- function(variable) {
  if (variable %in% names(figure_labels)) {
    unname(figure_labels[[variable]])
  } else {
    variable
  }
}

Saving a figure

save_figure() writes a figure at its printed size in millimetres, in each format needed: PDF and SVG, which keep lines and text sharp at any zoom, for journals; and PNG for the website. The PDF device embeds fonts and handles symbols such as the dagger (†). Nothing in the analysis saves a figure yet; this is the function to use when it does.

Click to show/hide R Code 
# Save a figure at its printed size, in millimetres: PDF (cairo, which embeds
# fonts and handles symbols such as the dagger) and SVG for journals, PNG
# (ragg) for the website. Returns the paths written.
save_figure <- function(plot, file, width, height,
                        formats = c("pdf", "svg", "png"), dpi = 600) {
  devices <- list(
    pdf = grDevices::cairo_pdf,
    svg = svglite::svglite,
    png = ragg::agg_png
  )
  paths <- paste0(file, ".", formats)
  for (i in seq_along(formats)) {
    ggplot2::ggsave(
      paths[i], plot,
      device = devices[[formats[i]]],
      width = width, height = height, units = "mm", dpi = dpi,
      bg = "white"
    )
  }
  invisible(paths)
}

The default theme

Setting the theme once makes it the starting point for every figure, including quick ones made while exploring. The figures in Figures also add it themselves, so each figure looks the same however it is printed, including in the snapshot tests.

Click to show/hide R Code 
# Every figure starts from this theme unless it sets another
ggplot2::set_theme(theme_publication())

For more on themes and on choosing colours, see Fundamentals of Data Visualization by Claus Wilke.
